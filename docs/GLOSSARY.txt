USAGE. Terms below are used EXACTLY as defined across all docs/*.txt.
Columns: TERM | DEFINITION | FIRST-USED-IN (document §).

abi_ver custom section | wasm custom section (id 0) named "abi_ver" whose payload version byte the kernel checks at instantiation; refusal for mismatch | IFSPEC 6
ABI v1.1 | frozen guest-facing contract revision documented in abi/ABI.md, adding LOGIN op, abi_ver rule, reply-channel convention, routed path ops | SDD 1.3
audit record | serial line "[audit] sid= uid= op= reason= target=" emitted on every rejected privileged operation | IFSPEC 8.1
backend swap | replacing a device-window backend (e.g. RAM-disk -> virtio-blk) with zero guest-visible change | SDD 12.3
bind / binder | attaching a handle to an existing port name; binders fan in and share the port's FIFO ring | IFSPEC 4.2
block window | device window class 1 implementing polled block I/O mailbox per ABI §3 | IFSPEC 5.2
boot preload table | kernel-resident images[8] of module blobs preloaded from the ESP; SPAWN resolution source until fs exists | SDD 7.2
boot_info | struct passed from efi_main to kmain carrying mmap + preloaded payloads | SDD 4.2
Bus | host-side implementation of guests/lib Kernel mirroring core/ports.cc decision-for-decision; Yield parks 20 us since SVC 88ed8a7 | SDD 14.2
capability bit | one of bits 0..7 of a u64 capmask (KILL DEVMAN POWER FOCUS FS_ADMIN NET_ADMIN SPAWN CONF) enforced by the kernel registry | IFSPEC 7.3
capmask | u64 capability mask held per session; granted only via LOGIN at login time or bounded SPAWN | SDD 8.2
class (device) | numbered device-window class: 1 block, 2 net, 3 input, 4 timer, 5 console; 6..9 reserved | IFSPEC 7.5
console window | class-5 output window at +0xF000/+0xF008 of session linear memory | IFSPEC 5.1
core/ | arch-blind substrate layer: no #ifdef, no inline asm, no direct hardware access | SDD 3.1
cooperative RR | round-robin scheduling that switches only at yield/exit/import points; binding policy through Phase 7 | SDD 3.6
crash isolation | property that a guest fault or KILL ends only that session, never the kernel | SDD 6.5
datagram | one port message of <=4096 bytes copied by the kernel, no shared memory | IFSPEC 4.2
devman | kernel-owned endpoint enumerating device instances (ENUM op, needs CAP_DEVMAN) | IFSPEC 7.5
Direct client | RPC pattern replying onto the sending handle itself; used for kernel endpoints | SDD 14.3
ESP | EFI System Partition (FAT), source of \vm\app* and /boot/modules/* | SDD 4.2
engine | adapted wasm3 instance set (environment/runtime/module) owning exactly one session's execution | SDD 6.1
FakeKernel | host test double supplying registry/devman/power endpoints for guests/lib tests | SDD 14.2
fan-in | many binders receiving from one port name via the shared ring | IFSPEC 4.2
FAT16 | filesystem implemented by fs.wasm (8.3 names, 512 B sectors) over the block window | SDD 13.4
focus | kernel-owned attribute selecting which session receives §4 input records; moved by kern_focus_set | IFSPEC 5.3
fs protocol v0 | lane-local request/reply op set of fs.wasm (STAT LIST READ WRITE CREATE MKDIR DELETE; statuses -1..-9) | IFSPEC A.2
gate (phase gate) | string assertions on stripped ANSI serial output that mark a phase complete (make test-pN) | SDD 15.3
guest ABI stability | rule that .wasm modules never need recompilation across kernel versions/architectures | SDD 3.5
handle | small non-negative per-session port index, 8 per session, -1 invalid | IFSPEC 4.3
hosteng | host build of the engine used to run .wasm modules with stub imports; availability pending MAINLINE | SDD 13.7
Inbox client | RPC pattern where the requester owns a uniquely named inbox port declared in each request; used for user servers | SDD 14.3
init.conf | boot config listing servers "<name> <path> <capmask-hex> [respawn]"; delivered to init.wasm via argv text | IFSPEC A.4
kernel.conf | key=value knob file applied by init via proposed SETCONF, never parsed by the kernel | SDD 13.6
KERNEL-OK | success sentinel printed by kmain after sched_run returns with all sessions dead | SDD 15.3
kern_* imports | extension functions in wasm import module "kernel" (currently the four port calls) | IFSPEC 4.1
lane | parallel worktree branch: MAINLINE(master), SERVICES(lane/services), TOOLS(lane/tools), DOCS(lane/docs), VERIFY(lane/verify) | RELHIST 1
LOGIN (op 5) | registry operation granting {uid,capmask} to a named session; callable only by owner of "login" | IFSPEC 7.4
kern_blk_read / kern_blk_write | ABI v1.1 managed-runtime block transport imports (lba, ptr, count -> 0 | -1) served by devblk_rw; the §3 window remains the contract for raw/native guests | IFSPEC 4.1
mini-WASI | the frozen preview1 subset implemented natively by the substrate | SDD 3.4
mkpefi.py | host script converting linked ELF to PE32+ acceptable to OVMF (80-byte DOS stub etc.) | SDD 4.2
msg | port queue element {from_sid,len,data<=4096} | SDD 9.2
owner | the single session that created a port name; creation fails if name exists | IFSPEC 4.2
poll budget | number of yield-poll iterations before RPC gives up (DefaultRecvBudget 200000) | SDD 14.3
port | kernel-relayed datagram channel: {name, owner sid, FIFO ring depth 32} | SDD 9.2
power | kernel-owned endpoint for REBOOT/OFF (needs CAP_POWER); halts after reply in v1 | IFSPEC 7.6
preemptive RR | Phase-8 scheduler mode driven by timer IRQ quantum; cooperative fallback retained | SDD 3.6
preview1 | wasi_snapshot_preview1 import namespace; only the frozen subset is honored | IFSPEC 3
quantum | scheduler time slice; cooperative now, configurable via kernel.conf at Phase 8 | SDD 3.6
RAM-disk backend | v1 block backend: 16 MiB mm-allocated disk served through devblk_poll between quanta | SDD 12.3
raster-free console | output model where all guest output flows as hex/byte writes to the console window (no framebuffer in v1) | SDD 12.2
routed fd | session fd >= 3 mapped to an fs.wasm file handle by the kernel-routed preview1 path ops | SDD 11.3
registry | kernel-owned endpoint for LIST/CAPS/KILL/SPAWN/LOGIN | IFSPEC 7.4
ReplyBook | server-side cache binding each client inbox name once (kernel has no unbind) | SDD 14.3
reply-channel convention | v1.1 rule: requests carry rname; responder replies into that existing port; empty = synchronous | IFSPEC 7.2
respawn policy | init supervision column deciding whether a dead server is restarted; give-up cap after repeated deaths | SDD 13.6
sched_wasi_state | per-session WASI state: argv, exit flag/code, routed fd table (64 entries) | SDD 7.2
session | one wasm instance scheduled on its own native stack, addressed by sid (0 = kernel) | SDD 7.1
session states | FREE/RUNNABLE/RUNNING/ZOMBIE lifecycle bytes reported by LIST | SDD 7.2
SETCONF | registry op 6 (ratified v1.1): {key[16],u64 value} applies kernel knobs; needs CAP_CONF bit7; intended caller init.wasm; kernel implementation pending | IFSPEC 7.4
shim | tiny native device driver (<=300 LOC) owning hardware and exposing one class window | IFSPEC 9.1
sid | session identifier, array index into sessions[12]; sid 0 is the kernel | SDD 7.2
SPAWN (op 4) | registry program launch: instantiate preloaded module with exact requested capmask, never exceeding caller rights | IFSPEC 7.7
substrate freeze | rule limiting native code to mechanism: boot+mm+scheduler+engine+WASI glue+device shims | SDD 3.3
tools/img | TLS-lane Go FAT image builder replacing mtools flow (BPB-parity tested) | SDD 15.5
trampoline | sched_session_main entry frame built by ctx_make; RIP slot at highest address | SDD 7.3
well-known names | console fs net login shell (user) + registry devman power (kernel) | IFSPEC 4.2
window | region of a session's linear memory assigned by the kernel; guests use offsets only | IFSPEC 1.2
BLOCKER / MAJOR / MINOR / NOTE | severity classes of the VERIFY lane review ledger; BLOCKER = ABI violation or capability gap and gates QA intake before any MAIN commit | GLOSSARY (this entry); SDD 16.7
canonical header | the single §7 request framing, 24-byte {u16 op,u16 seq,u32 uid,char rname[16]} per ABI v1.1; kernel side conforms (F15 closed), legacy senders tracked under F2a | IFSPEC 7.2
cross-lane contract notes | MEMORY.md section pinning ABI-NOTES.md instantiations (block-window alignment, inbox reply convention, FS op mapping); superseded by the ABI v1.1 RATIFICATION for the items it covered | SDD 12.3
FINDINGS.txt | append-only review ledger of the VERIFY lane (/home/cyr/kernel-lane-verify/verify/), one numbered finding per defect with severity | SDD 16.7
owner-vs-binder rule | a port's LOGIN-relevant ownership belongs to its creator only; binders must never satisfy owner checks (kernel fix tracked as FINDINGS F13) | IFSPEC 7.4
QA intake | binding MEMORY.md policy: read FINDINGS.txt before committing to MAIN; fix or rebut open BLOCKERs first | SDD 16.7
uid stamping | ratified v1.1 rule that port_send OVERWRITES the datagram uid with the sending session's registry uid (spoof-proof identity); implementation pending (FINDINGS F32) | IFSPEC 7.2
v2 roadmap | ABI §11: scheduled items NOT in force until individually ratified -- kern_port_reply one-shot reply caps, LIST/CAPS gating at Phase 10, IRQ arms post-P9, §9 class layouts | IFSPEC 11
